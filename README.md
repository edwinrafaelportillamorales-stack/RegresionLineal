# RegresionLineal

## Descripcion
Programa desarrollado en Java que implementa la regresion
lineal simple mediante el metodo de minimos cuadrados.
Tambien calcula el coeficiente de correlacion de Pearson
y el coeficiente de determinacion R2.

## Requisitos
- Java JDK instalado.
- Git instalado.

## Clonar repositorio
git clone URL_DEL_REPOSITORIO

## Compilar
javac Ajuste_de_Funciones/*.java

## Ejecutar
java Ajuste_de_Funciones.Main
